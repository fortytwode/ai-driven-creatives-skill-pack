# Flat Script Rewriter

Takes a draft ad script that reads like generic AI output and rewrites it using the Setup / Shift / Proof / Payoff structure. Catches dangling phrases, stacked fragments, missing context, and other AI tells.

## When to use

Whenever an AI script reads "fine on the page but falls apart out loud." This is the single biggest quality lift you can apply to AI-generated copy.

## How to use

Copy the prompt below into Claude or ChatGPT. Paste your flat script where indicated. Run. Read the output aloud.

## The prompt

```
Below is a draft ad script that reads like generic AI output. Rewrite it.

Apply this exact four-part structure: Setup (the opening situation or problem), Shift (what changes once the product appears), Proof (a concrete screen, behavior, or result), Payoff (what to remember or do next).

Fix all of the following:
- Choppy two and three word fragments. Replace with flowing sentences.
- Dangling phrases that read incomplete.
- Stacked short fragments that read like a robot.
- Missing context (e.g., "5 minutes after" with no anchor).
- Sentences that start with the product name.
- Generic claims with no specificity.
- Feature list framing instead of story framing.
- A resolution that lists features instead of showing one lived moment.
- Several situations named in passing instead of one situation gone deep.

Constraints:
- 45 to 65 words. Never over 70.
- Conversational, first-person.
- Open on the pain, close on the gain.
- Keep only the one un-fakeable detail that does the most work. Cut the rest.
- Do not fall back to a familiar template (PAS, AIDA, BAB) on autopilot. Build on the Setup / Shift / Proof / Payoff beats, with the bet and craft constraining each beat.
- No em dashes or en dashes.
- Must pass a read-aloud test at natural pace.

Original draft:
[PASTE FLAT SCRIPT HERE]

Output the rewritten script, with each beat labeled, plus a one-line note on what you changed and why.
```
